| Hoenn (Region 3) | 202 | 202 | 0 | Ruby/Sapphire (Original Hoenn Dex) |
| Sinnoh (Region 4) | 151 | 210 | +59 | Updated from Diamond/Pearl (151) to Platinum (210) |
| Unova (Region 5) | 156 | 301 | +145 | Updated from Black/White (156) to Black 2/White 2 (301) |
| Kalos (Region 6) | - | - | 0 | *Not yet configured in `pokedexIndexes.js` (457 combined)* |
| Alola (Region 7) | - | - | 0 | *Not yet configured in `pokedexIndexes.js` (403 USUM)* |
| Galar (Region 8) | - | - | 0 | *Not yet configured in `pokedexIndexes.js` (400)* |
