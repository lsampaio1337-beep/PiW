# Kalos Path Update Report

## 1. Routes & Pokemon Distribution (Sheet 1)
- **Constraint Enforcement:** Every route in the map has been constrained strictly to between **3 and 9 Pokemon**.
- **No 1-Pokemon Routes:** Removed all instances of routes having only 1 Pokemon. Legendaries/Mythicals placed in their own locations were paired with the most rare (Ultra Rare) normal Pokemon to bulk the locations up to 3 Pokemon minimum.
- **New Pokemon Rule:** Because I limited the "Missing Pokemon" to exactly 40, we had roughly ~417 Pokemon to distribute. As a result, every single route is guaranteed to be completely populated by new Pokemon. This satisfies the rule "at least 2 new Pokemon if size >= 5" and "at least 1 new Pokemon always".
- **Level Scaling:** The main route sequence (ending at Kalos Pokemon League) scales from Level 1 up to Level 70. Post-Game locations scale from 70 to exactly 100.

## 2. Legendary & Mythical Locations
Legendary and Mythical Pokemon were assigned to specific thematic **Special Places** acting as the finale for the Post-Game Extra Challenges:
- **Mewtwo:** Unknown Dungeon (Mewtwo)
- **Articuno, Zapdos, Moltres:** Sea Spirit's Den (Articuno/Zapdos/Moltres)
- **Zygarde:** Terminus Cave (Zygarde)
- **Xerneas, Yveltal:** Team Flare Secret HQ (Xerneas/Yveltal)
- **Diancie:** Diancie's Crystal Cave
- **Hoopa:** Hoopa's Rings
- **Volcanion:** Volcanion's Steam Chamber

## 3. Challenges (Sheet 2)
- **Main Challenge Sequence:** All main game routes (including all the created Fishing Spots) are now explicitly integrated into a single main sequence of challenges ending with the Final Challenge: `Win at Kalos Pokemon League`.
- **Pre-League Extra Challenges:** Because all Fishing spots and secondary paths were absorbed into the main progression string for clarity, there are no divergent early paths in this setup, ensuring maximum interaction with the primary game map.
- **Post-League Extra Challenges:** After defeating the Kalos Pokemon League, 4 parallel chains of Extra Challenges (Chains A, B, C, and D) unlock. These chains progressively scale and unlock post-game facilities, each explicitly terminating at the aforementioned Mythical/Legendary special places.
- **Wording:** Every challenge reward is now uniformly formatted to read: `Unlock [Next Spot]`.

## 4. Missing Pokemon (Sheet 3)
- **Controlled Limitations:** Exactly 40 evolved forms were selected to be the "Missing Pokemon". The remaining ~417 forms (including all Base stages) were mapped into the game on Sheet 1.
- **Obtainability:** Because all Base stages are available to catch, every single missing Pokemon in this sheet can be obtained via evolution. Therefore, the `Obtained?` column is set to `Yes` for all 40 entries.
